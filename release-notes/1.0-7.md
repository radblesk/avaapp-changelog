## Interaction Update

This update fixes many issues regarding content interactions, hit areas and also adds new ways to interact with
content and menus.

### What's Changed

#### Fixes

* An issue where tapping near post media could accidentally open the media
* An issue where tapping near comment media or bottom row could accidentally open the media instead collapsing
  comment
* Hiding over 50 posts at once returns bad request error, added sequential batching
* Incorrect subreddit data returned from Reddit might cause decoding error (observed in search view)
* Random 500 errors might occur when fetching inbox
* Quickly opening and closing post prevents it from being marked as seen
* Some other smaller behind-the-scenes bug fixes and improvements

#### New Features

* Disable video scrubbing while scrolling to prevent accidental touches
* Long press on any media to open context menu (works for both, posts and comments)
* Long press on post to open post options menu (OPTIONAL! If disabled, classic 3-dot menu icon is displayed
  instead)
* Increased hit area for comment menu button
* Multi's toolbar now have a button to display all subreddits in current multi, allowing direct navigation to
  specific subreddit

### From Feedback

* If you have questions about Ava, feel free to join a Discord server. Link can be found in Settings -> About.
* **Tapping current tab returns to sidebar behavior**: this is a default behavior controlled by Apple. In SwiftUI,
  there is
  no way around this. I am investigating this request, but no promises yet. I don't want to introduce custom solution
  that might break iPad or iPhone Duo compatibility, which Ava currently has.

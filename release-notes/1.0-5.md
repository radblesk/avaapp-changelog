## Bug fixing update based on users feedback and crash reports

This update brings many improvements and bug fixes reported from TestFlight.

### What's Changed

#### Fixes

* Adding/removing value to user settings causing data error resulting in settings reset to default values
* String catalog out of date, localized string typos
* Loading profile and trophies might cause render loop caused by recursive layout recalculations resulting in app
  crash
* Marking already read inbox/announcements messages as read, causes Reddit server to return error 400
* Inbox list selection passing incorrect identifier, incorrect condition filtering out unread announcements
* Posts containing URL without host component causing a fatal crash
* Fetching moderator permissions for user, displaying only eligible actions for posts and comments
* Compact posts now respect subreddit on top and subreddit icon toggles
* Triggering scroll-to-comments sometimes skips entire comment section **(needs testing)**

#### New Features

* You can now pick if voting buttons for compact posts are displayed on the left or right side by

#### Improvements

* More aggressive disk media caching causing lower memory usage

**Thanks to everyone who contributed with feedback!**

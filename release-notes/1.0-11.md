### Content Focused Update

This update brings new ways to display and interact with the content in Ava, safeguards if Reddit changes
their API access to reduce 403 errors, and some other odds and ends.

### What's Changed

#### Fixes

* An issue where 'Clear cache' might fail to remove some media cache
* An issue where subscribe/unsubscribe does not automatically update sidebar subreddits list
* An issue where Reddit video download might return an error on save
* An issue where Reddit video with audio might be downloaded without it
* Search works again after Reddit API changes

#### New Features

* Customizable **swipe gestures** for posts and comments (vote, save, share, reply and more)
* A picker to change style of the top toolbar background (system, hard, soft)
* Search posts inside Multi-reddits
* A **Report Summary** option in post summaries for easier reporting of incorrect post summarization
    * Note: Summary report is anonymous. It includes post content, post ID, generated summary and your device data. It
      does not include any personal or Reddit account data.
* **Streamable** videos can now be played directly in Ava (sharing and download works as well)
    * Note: if Ava fails to resolve link through Streamable API, it falls back to link preview.
    * **Important**: In my internal testing, Streamable's CDN link resolved from their API is very slow, even outside
      Ava. Please report any playback issues, preferably with a region you are connecting from (USA, Canada,
      Europe,...).

#### Improvements

* Ava can now automatically attempt to fix a failed Reddit endpoint, cache fix and automatically reports affected 
  endpoints
* Added endpoint level overrides for session authentication and new OAuth session request handler
* Static media now require less data and time to fetch and cache
* Static media are now using custom image request with proper resizing to avoid unnecessary overhead
* Static media prefetching now correctly respects order of posts
* Shared image processor resizing and scaling improvements
* Caching improvements
* Changing comments sort scrolls back to the first comment now
* Top toolbar now automatically minimizes on scroll if there is not enough screen space on iOS27+
* **What's New** page improvements after internal Ava Web API changes
* Other smaller under-the-hood improvements

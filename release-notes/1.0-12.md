## Universe Fixing Update

This update is mainly focused around fixing bugs and failing Reddit endpoints, but it also adds some useful features 
and improves the balance of the universe.

### What's Changed

#### Fixes

* Link previews with missing thumbnails might have extra top padding
* An issue where some videos with small height might crop the controls
* An issue where feeds with sorting set to New, Hot, Raising stopped loading
* An issue where loading more comments returned failed endpoint error
* Subreddits/Multireddits with no posts show placeholder and loading indicator at the same time
* An issue where some post cards might have extra top padding
* An issue where invalid/incomplete server response might crash the app
* An issue where error returned when creating new comment might crash the app

#### New Features

* New comments highlighter
* Hide seen posts button in Multi's toolbar (hides seen posts until the next refresh)
* You can now specify which media type can autoplay (all, GIFs, videos)
* Added 'Share as Image' to Post and Comment swipe actions

#### Improvements

* Split views layout and color improvements
* More flexible sidebar/content size
* Swipe actions indicator animations
* Added new automated recovery attempt if Reddit endpoint fails
* Static media prefetching and caching improvements
* Long-press on post preview now has rounded corners
* Other under-the-hood improvements

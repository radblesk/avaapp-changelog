## Performance & Reliability Update

This update focuses on making Ava faster, smoother and more reliable. It brings improved media performance, clearer
error messages, major stability improvements and fixes for features affected by recent Reddit API changes.

### What's Changed

#### Fixes

* Resolved issues preventing additional comments from loading
    * Note: this fix needs further testing to confirm long-term reliability
* Restored Trending Subreddits in the Search tab after Reddit API changes caused it to stop working
    * Note: this fix needs further testing to confirm long-term reliability
* User profiles, multi-reddits and search results now correctly scroll back to the top when changing sort order
* Canceled requests no longer display unnecessary error notifications
* Error notifications no longer display raw HTML responses or technical decoding errors
* Add/Remove Friend button is now only available to Reddit Premium users, matching Reddit's behavior
* Various smaller bugs and stability issues

#### Improvements

* Completely reworked error and response handling for more reliable operation
* Error notifications now provide clearer, more user-friendly explanations
* Improved automatic error reporting to help identify and resolve issues more accurately
* Improved media caching, prefetching, processing and playback for smoother scrolling and faster media
  loading
* Various behind-the-scenes performance and reliability improvements

## Stability and Privacy Update

This updates brings stability and privacy improvements.

### What's Changed

#### Fixes

* Broken pagination in sidebar with more than 100 subreddits incorrectly fetching subreddits data
* Stale fetch operations prevent pull-to-refresh in feed views
* Changing tab or switching apps might throw 'cancellation' error when fetching trending subreddits
* Possible fix for some users experiencing app crashes during search autocomplete (report back)

#### New Features

* Added 'Auto-Hide Toolbar' option to iPad (iPad's tab bar is persistent unlike iOS tab bar, so on iPad only
  top toolbar is hiding)
* Added option to expand all comments by default

#### Improvements

* Sentry privacy improvements
* Increased legibility of post texts for both title and body (report back if not enough)

#### Debug

* Added deeper tracking for posts hiding failures as they keep throwing Bad Request errors for some users
* Improved HTTP error tracking and fingerprinting

## Accessibility and Usability Update

This update fixes many Compact posts and accessibility issues and adds new components support in Markdown.

### What's Changed

#### Fixes

* Link hit areas was still overlapping causing accidental link taps
* Issue in build 7 where long press on media prevents videos from being opened in fullscreen
* Unavailable media label now only shows icon for compact posts
* Crosspost in compact posts might be unclickable
* Compact post media overlay might prevent media tap gesture
* Oversized link media might increase hit area
* Soft line breaks are ignored by Ava's custom Markdown renderer, causing single "enter" to render on the same line
* Opening videos fullscreen may sometimes result in undismissable blank screen and app restart is needed
* Add/remove friend results in error 403
* Smaller behind-the-scenes bug fixes and improvements

#### New Features

* Added option to hide post voting buttons
* Compact posts media overlay are now smaller in the right bottom corner, rather than covering media in the
  middle
* Added stepper to change title line limit for compact posts
* Added picker for compact posts thumbnail size (default, bigger)
* Added long press to open context menu for galleries in compact posts
* Videos in compact posts now also have long-press to open context menu like other media
* Added RedGifs indicator for compact posts thumbnail
* Add skip comment button with editable position (left, middle, right)
* Added nested lists support to Ava's custom Markdown renderer
* Added divider support to Ava's custom Markdown renderer
* Added tables support for Ava's custom Markdown renderer

#### Debug

* Added automatic error reporting while fetching trending subreddits to help investigate and fix 'Invalid
  Response' errors while fetching them
